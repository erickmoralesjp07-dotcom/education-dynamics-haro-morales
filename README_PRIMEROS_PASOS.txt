PROYECTO EDUCATION DYNAMICS - PRIMEROS PASOS

1. Instale Anaconda Distribution.
2. Extraiga esta carpeta dentro de su carpeta Articulo.
3. Abra Anaconda Prompt.
4. Escriba: cd /d "RUTA_COMPLETA_DE_ESTA_CARPETA"
5. Escriba: 01_crear_entorno.bat
6. Espere hasta que aparezca ENTORNO CREADO Y VERIFICADO CORRECTAMENTE.
7. Para abrir JupyterLab, haga doble clic en 02_abrir_jupyterlab.bat.

No guarde archivos modificados dentro de data/raw.
