# Modeling Global Educational Dynamics

**Authors:** Haro and Morales

Reproducible research project for analyzing the dynamics of educational access, quality, inequality, and resources using UNESCO UIS and PISA data.

## Current status

- Anaconda environment configured.
- Jupyter kernel validated.
- Project directories created.
- Parquet reading and writing verified.
- UNESCO UIS source discovery notebook prepared.

## Data policy

Raw and restricted data are not stored in this repository. PISA microdata and large UIS files must be obtained from their official sources.

## Main tools

- Python 3.12
- Anaconda
- JupyterLab
- pandas and Polars
- SciPy and statsmodels
- scikit-learn

## Repository structure

- notebooks: reproducible analyses
- scripts: reusable programs
- data/metadata: data dictionaries and provenance
- results: figures, tables, and diagnostics
